LISTA DE COMPRAS - GERAR APK PELO GITHUB

Este projeto contem o codigo Flutter e um workflow que compila o APK na nuvem.

COMO USAR:
1. Crie uma conta ou entre em https://github.com
2. Crie um repositorio novo chamado lista-compras.
3. Extraia este ZIP no computador.
4. Envie todos os arquivos e pastas extraidos para o repositorio GitHub.
   IMPORTANTE: envie tambem a pasta oculta .github.
5. No repositorio, abra a aba Actions.
6. Se aparecer uma solicitacao para habilitar Actions, habilite.
7. Abra "Gerar APK Android" e clique em "Run workflow".
8. Quando terminar com sucesso, abra a execucao concluida.
9. Na parte inferior, em Artifacts, baixe "lista-compras-apk".
10. Extraia o ZIP baixado. Dentro dele estara app-release.apk.
11. Envie app-release.apk para o celular Android e instale.

OBSERVACAO:
Esta primeira versao ainda nao salva os produtos depois de fechar o aplicativo.
